# dsh-connector 使用说明

## 网络前提(先读这个)

App 用你系统的普通网络建 SSH 隧道,不自带代理。办公室/外网电脑要连到家里的服务器:

1. **服务器有公网 IPv6**(`240e:`/`2001:` 开头),dsh 所在机器拿得到;
2. **跑 App 的电脑也有 IPv6**(办公室/手机 4G 一般有);
3. **光猫/路由器防火墙不放行入站 22 就没戏**——家宽被运营商随机封端口的情况存在,封了就连不上(自检:`ssh -v <用户>@<地址>` 看能否 established);
4. 家宽 IPv6 常变,建议 DDNS(域名 + AAAA),App 里填域名最省心。

自检命令(在跑 App 的电脑上):`ping -6 <服务器地址>` 通、`ssh -v <用户>@<地址>` 不卡在连接阶段,就 OK。
(其他能 `ssh` 通的组合同样可用:IPv4+端口映射、Tailscale 等 overlay。)

## 环境要求

- Windows 10/11(Win11 自带 WebView2,Win10 需额外安装)
- 系统 OpenSSH 客户端:设置 → 应用 → 可选功能 → 添加 "OpenSSH 客户端"

## 三步上手

### 第 1 步:私钥就位(只需一次)

**不懂 SSH 密钥的小白,直接用 App 里的"密钥管理"**(配置页下方):

1. 填一个私钥保存路径(默认已帮你填好 `~/.ssh/id_ed25519`);
2. 点 **① 生成密钥对**——自动生成密钥、自动修好 Windows 权限;
3. 把文本框里给出的**一行命令**粘到任意终端执行一次(会问一次你的服务器密码,这是正常的)——公钥就装到服务器上了;
4. "私钥文件路径"已自动填好,**保存配置 → 连接**。

**想自己来的**,手动版:

```powershell
# 从服务器拉私钥(你已经有钥匙对的情况)
scp <用户名>@<服务器地址>:~/.ssh/id_ed25519 $env:USERPROFILE\.ssh\id_ed25519
```

收紧权限——Windows OpenSSH 对私钥权限挑剔,太宽松会直接拒用:

```powershell
icacls $env:USERPROFILE\.ssh\id_ed25519 /inheritance:r
icacls $env:USERPROFILE\.ssh\id_ed25519 /grant:r "$env:USERNAME:R"
```

### 第 2 步:启动并配置

双击 `dsh-connector.exe` → 出现配置页(之后也可从**托盘右键 → 连接配置**打开):

| 字段 | 填什么 |
|---|---|
| 主机地址 | 服务器的 IPv6 或域名(如 `2001:db8::1`、`example.com`) |
| SSH 端口 | 一般 `22` |
| 用户名 | SSH 登录用户名 |
| 私钥文件路径 | 第 1 步里的路径 |
| 本地端口 | `18080`(**固定勿改**——dsh 的 cookie 绑 localhost authority,换端口即失效) |
| 远程端口 | `3080`(dsh web 默认) |
| 服务器 dsh 日志路径 | dsh 的日志文件(如 `/path/to/dsh/dsh.log`),App 从这里 grep 当前 token |

保存 → 连接。几秒后同一窗口自动变成 DSH WebUI。

## 日常形态(托盘化)

- **关闭窗口 ≠ 退出**:App 退到系统托盘,隧道继续跑,连接不断;
- **左键**点托盘图标 = 显示/隐藏主窗口;**右键** = 菜单:
  - 显示/隐藏主窗口
  - 重新获取凭据 / 断开连接
  - 测试连接(诊断) / 运行日志 / 连接配置
  - 退出(真正退出,自动清理隧道)
- 托盘图标:🟢 一切就绪 / 灰 = 未连接或有异常;鼠标悬停看实时状态。

## 下载

在 WebUI 里点任何下载,自动弹出下载窗口:

- 进度条 + 实时速度 + 已下载/总大小 + **取消**;
- 文件存到 `C:\Users\<你>\Downloads\`,重名自动加 `(1)(2)`;
- "打开下载文件夹"按钮直达。

> 下载入口来自 dsh 的**侧边栏插件** `dsh-better-sidebar`(原版 dsh 侧边栏没有下载按钮)。没装的话:
> ```bash
> npx @deepseek-ai/dsh plugin --profile web add dsh-better-sidebar
> ```
> 装完重启 dsh web 即可。App 的其他功能不依赖此插件。

## 排障

| 现象 | 解法 |
|---|---|
| 日志 `Permission denied` / 一连上就断 | 私钥权限:重跑第 1 步的两条 icacls |
| 一直"隧道未连接" | 地址是否变化;点"测试连接"看详细诊断日志 |
| WebUI 显示 401 | 等 3 秒——看门狗会自动修;仍未好就点"重新获取凭据" |
| 想看 App 在干什么 | 托盘右键 → 运行日志 → 复制日志 |

日志同时落盘在 `%APPDATA%\com.dsh.connector\dsh-connector.log`,重启后自动加载上次日志尾部。

## 深浅色

配置/日志/下载三个窗口右上角的 ☀/🌙 按钮,一键切换;三窗联动,选择持久化。
